# Immersive Bag Skin

Give BetterBags Next the look of WoW Forever's stock backpack. The Forever Backpack theme brings back the metal frame, round bag portrait, gold headings, search and sort controls, and coin box.

## Install

1. Install [BetterBags v0.9.3](https://www.curseforge.com/wow/addons/better-bags/files/9635058) for WoW Forever 1.60.1.
2. Grab the install ZIP from [GitHub Releases](https://github.com/RozziP/immersive-bag-skin/releases) and extract `ImmersiveBagSkin` into `_forever_/Interface/AddOns`.
3. Restart WoW, enable both addons, and open your bags. On first login, the addon selects a separate **Forever Backpack** profile and reloads the UI once.

Click the backpack portrait for BetterBags options or to switch between **Show Categories** and **Show Blizzard Bags**. Shift-right-click a section heading to rename it. Save a blank name to restore the original heading.

Switch back to your old profile in BetterBags settings under **Profiles**. To use the look with another Next profile, select **Forever Backpack** under **Appearance → Theme** and click **Apply Theme**.

Built on BetterBags Next's Plain theme using Blizzard's in-game art.
